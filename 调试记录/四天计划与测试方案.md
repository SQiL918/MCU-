测试条件固定：同一地面、同一光照、同一胎压/轮胎清洁、同一电池起始电压、同一场地位置。每次测试前把车放回 A 点同一位置/方向。

## 4. 每次跑车前后检查清单

跑前：

- [ ] 电池电压 ≥ 约定值（满电或 ≥ 7.4 V，按实际电池）
- [ ] 轮子/电机线/传感器线无松动
- [ ] 灰度镜头干净，高度未变
- [ ] IMU 固定牢，yaw 已归零/无漂移
- [ ] 场地 A/B/C/D 位置未动
- [ ] OLED 显示模式/速度正确

跑后：

- [ ] 记录时间、脱线、漏提示、停车位置
- [ ] 摸电机/驱动是否过热
- [ ] 检查电池电压
- [ ] 保存异常现象（视频/照片）
- [ ] 如果改了参数，记下旧值/新值

## 7. 时间不够时的取舍

优先级从高到低：

1. Q1 + Q2（35 分）——必须保。
2. OLED + 调速（5 分）——成本低，必须保。
3. 报告（20 分）——格式完整就能拿大部分。
4. Q3（30 分）——在 Q2 稳定后冲。
5. Q4（30 分）——Q3 稳定后再冲。

**不要为了 Q4 牺牲 Q2**：Q2 跑不稳，Q3/Q4 更不可能；而且 Q2 是基础。

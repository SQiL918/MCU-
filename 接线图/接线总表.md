# 第16队 自动行驶小车 接线总表

> 适用硬件：STM32F103C8T6 Blue Pill + TB6612FNG + 2×WHEELTEC MG513 编码电机 +
> CH32V006 八路灰度 + MPU6050 + 0.96" SSD1306 OLED + P03B 稳压模块。
>
> **接线前必须做三件事**
> 1. 断电，万用表蜂鸣档确认电池正负极、开关、保险丝通路；
> 2. 先接 GND，再接电源，最后接信号线；
> 3. 第一次上电用 12 V 限流电源（限流 0.5 A），确认无短路后再接电池。

---

## 1. 供电关系（先看这一节）

```
3S 锂电池 (11.1 V / 12.6 V 满电)
   │
   ├─[5 A 保险丝]─[船型开关]─┬─→ P03B VIN+          → 5 V / 3.3 V
   │                          └─→ TB6612 VM           → 电机功率
   │
   └────────────────────────────→ 公共 GND（星形汇接点）

P03B 5V  → Blue Pill 5V、灰度模块 +5V、蜂鸣器 +5V
Blue Pill 3.3V（由其 5V 经板载 LDO 产生）
         → MPU6050 VCC、OLED VCC、编码器 VCC、TB6612 VCC
```

> **3.3 V 只能二选一**：推荐用 Blue Pill 的 3.3 V 输出带 MPU/OLED/编码器/TB6612；
> 不要把 P03B 的 3.3 V 再接到 Blue Pill 的 3.3 V 引脚，否则会倒灌 Blue Pill 的 LDO。
> 如果 3.3 V 负载较重，可改用 P03B 3.3 V 直接供负载，但此时 Blue Pill 只接 5 V，
> 其 3.3 V 引脚悬空，不接负载。

| 电源 | 供给对象 | 备注 |
|---|---|---|
| 电池 12 V（VM） | TB6612 VM、P03B VIN | 电机电流不经过 5 V 稳压器 |
| 5 V | Blue Pill 5V、灰度 +5V、蜂鸣器 | 灰度模块 8 路红外约 150 mA |
| 3.3 V | MPU6050、OLED、编码器 VCC、TB6612 VCC | Blue Pill 的 3.3 V LDO 约 100 mA，足够 |

**禁止**：
- 不要把 P03B 的 5 V 输出和 MB-102 的 5 V 输出接在一起；台架调试只用其中一个。
- 不要把电机接到 5 V/3.3 V 排针上；电机只接 TB6612 的 AO1/AO2、BO1/BO2。
- 不要带电插拔电机 6P 端子；拔插前先断电。

## 3. TB6612FNG 模块

> 绿色模块丝印可能是 `PWMA AIN1 AIN2 STBY BIN1 BIN2 PWMB GND` + `VM VCC GND`，
> 不同批次顺序可能不同。**以模块丝印为准**，接线前用万用表确认 VM/VCC/GND 不与
> 电机输出短路。

| TB6612 端子 | 接到 | 说明 |
|---|---|---|
| VM | 电池 +（经保险丝/开关） | 12 V 电机电源 |
| VCC | 3.3 V | 逻辑电源，不要接 5 V |
| GND | 公共 GND | 至少两根 GND 都接 |
| STBY | 3.3 V | 高电平使能；也可接 PB11 做软件使能（本工程接 3.3 V） |
| PWMA | PA2 | 左电机 PWM，20 kHz |
| AIN1 | PA4 | 左电机方向 |
| AIN2 | PA5 | 左电机方向 |
| AO1 | 左电机 M1 | 电机线，交换 AO1/AO2 可反转 |
| AO2 | 左电机 M2 | 电机线 |
| PWMB | PA3 | 右电机 PWM，20 kHz |
| BIN1 | PB12 | 右电机方向 |
| BIN2 | PB13 | 右电机方向 |
| BO1 | 右电机 M1 | 电机线 |
| BO2 | 右电机 M2 | 电机线 |

- 在 VM-GND 之间并 **100 µF/25 V 电解 + 0.1 µF 瓷片**，靠近 TB6612。
- TB6612 连续电流 1.2 A/通道；MG513 堵转电流较大，**不要让轮子长时间堵转**。
- 方向约定：AIN1=1、AIN2=0 为前进；若装车后左轮后退，交换 AO1/AO2 两根线，
  或把 `app_config.h` 的 `MOTOR_LEFT_INVERT` 改为 1。

## 4. MG513 编码电机 6P 端子

> 6P 线序不同批次可能不同。**不要凭颜色直接插**，先按下面步骤确认。

### 4.1 万用表确认 6P

1. 断电，万用表电阻档：
   - 两根线之间约 **10~30 Ω**：这两根是电机绕组 M1/M2；
   - 剩下 4 根是编码器：VCC、GND、C1、C2。
2. 在 4 根编码器线中：
   - VCC-GND 之间有几 kΩ~几十 kΩ（板上有滤波/上拉）；
   - C1-VCC、C2-VCC 之间约 10 kΩ（上拉），C1-GND、C2-GND 约 20 kΩ。
3. 给编码器 VCC/GND 加 **3.3 V**（不要 5 V），手转电机：
   - C1、C2 对 GND 应在 0~3.3 V 之间跳变；
   - 两路相位差约 90°。
4. 确认后按下表接线。

### 4.2 接线

| 电机 6P | 左电机 | 右电机 | 说明 |
|---|---|---|---|
| M1 | TB6612 AO1 | TB6612 BO1 | 电机绕组 |
| M2 | TB6612 AO2 | TB6612 BO2 | 电机绕组 |
| VCC | 3.3 V | 3.3 V | **编码器电源用 3.3 V**，保护 PA6/PA7 |
| GND | 公共 GND | 公共 GND | 与主控共地 |
| C1 | PA6 | PB6 | A 相 |
| C2 | PA7 | PB7 | B 相 |

- 如果编码器在 3.3 V 下不工作（个别批次需要 5 V），改为 5 V 供电，并在 C1/C2
  与 STM32 之间串 **1 kΩ + 3.3 V 肖特基钳位**；或者把 C1/C2 换到 PB6/PB7 等
  FT 引脚（右电机已经是 FT）。
- 上电后手推车前进，串口应看到 `L=`、`R=` 为正；若为负，把该电机 C1/C2 对调，
  或改 `ENCODER_LEFT_SIGN` / `ENCODER_RIGHT_SIGN`。

## 5. CH32V006 八路灰度模块

模块 2×8 排针定义（面向模块，USB/接口朝下）：

```
上排：OUT-1  OUT-2  OUT-3  OUT-4  OUT-5  OUT-6  OUT-7  OUT-8
下排： +5V    TX     RX    GND    SCL    SDA   SWDIO  SWCLK
```

本工程只用 **并行输出**，不用 UART/I2C：

| 模块端子 | 接到 | 说明 |
|---|---|---|
| +5V | P03B 5V | 模块内部 3.3 V LDO |
| GND | 公共 GND | 必须共地 |
| OUT-1 | PB3 | 车头最左（以实物方向为准） |
| OUT-2 | PB4 | |
| OUT-3 | PB5 | |
| OUT-4 | PA8 | |
| OUT-5 | PA11 | |
| OUT-6 | PA12 | |
| OUT-7 | PA15 | |
| OUT-8 | PB14 | 车头最右 |
| TX/RX/SCL/SDA/SWDIO/SWCLK | 不接 | 留空，不要短路 |

- 模块输出 **黑线为高电平**（ADC > 2000，板载 LED 亮）；代码 `GRAY_BLACK_IS_HIGH=1`。
- 如果装车后发现左右相反，把 `app_config.h` 的 `GRAY_REVERSE` 改为 1。
- 推荐离地 **8~12 mm**，先用手在黑白胶带上来回移动，串口看 `g=` 位图是否翻转。
- 现有 10 芯排线如果已经压好，按“OUT1~8 + 5V + GND”用万用表逐根确认；
  不要假设排线顺序。

| 模块端子 | 接到 | 说明 |
|---|---|---|
| VCC | 3.3 V | 模块自带 LDO，3.3/5 V 均可；本工程用 3.3 V |
| GND | 公共 GND | |
| SCL | PB10 | 软件 I2C |
| SDA | PB11 | 软件 I2C |
| AD0 | GND | I2C 地址 0x68 |
| INT | 不接 | 本工程用 200 Hz 定时读取 |
| XDA/XCL | 不接 | |

- 模块自带 4.7 kΩ 上拉，不要再并外部上拉。

- 上电后保持静止 2 s 做零偏校准；串口会打印 `IMU calibration`。

## 8. 蜂鸣器、LED、按键、电池检测

### 8.1 蜂鸣器（必须有源）

```
P03B 5V ── 蜂鸣器 + ──┬── S8050 集电极
                       └── 1N4148 续流二极管（磁式蜂鸣器加）
PB0 ── 1kΩ ── S8050 基极
S8050 发射极 ── GND
```

- 使用 **有源蜂鸣器**（通电即响），高电平驱动；无源蜂鸣器需要 2 kHz PWM，本工程
  默认不支持。
- 蜂鸣器电流约 20~30 mA，必须经三极管，不要直接挂 GPIO。

### 8.2 LED

```
PB2 ── 330Ω ── LED 阳极 ── LED 阴极 ── GND
```

- 高电平亮；与蜂鸣器一起做“声光提示”。
- PC13 板载 LED 做 1 Hz 心跳，低电平亮。

### 8.3 按键

| 按键 | 一端 | 另一端 | 功能 |
|---|---|---|---|
| KEY_START | PA0 | GND | 启动/停止 |
| KEY_SPEED | PA1 | GND | 速度 300/450/600/750/900 循环 |
| KEY_MODE | PB15 | GND | 停车时 Q1→Q2→Q3→Q4 循环 |

- 内部上拉，按下为低；不需要外部上拉。
- 按键建议用 6×6 轻触开关，一端接 GPIO，一端接 GND。

### 8.4 电池检测

```
电池 + ── 100kΩ ──┬── PB1 (ADC1_IN9)
                  └── 22kΩ ── GND
                  └── 100nF ── GND
```

- 分压比 22/(100+22)=0.180；12.6 V → 2.27 V，16.8 V → 3.02 V，安全。
- 代码按 3.3 V 参考、12 位 ADC 换算；串口/OLED 显示 `bat=12.1V`。
- 低于 10.2 V 建议停车；低于 9.6 V 必须停车（3S 电池保护）。

## 11. 上电前检查清单

- [ ] 电池电压 10.8~12.6 V，极性正确；
- [ ] 保险丝、开关通路；
- [ ] P03B 5 V 输出对 GND 无短路（电阻 > 50 Ω）；
- [ ] 3.3 V 输出对 GND 无短路；
- [ ] TB6612 VM/VCC/GND 与电机输出 AO1/AO2、BO1/BO2 不短路；
- [ ] 所有模块 GND 共地；
- [ ] 灰度 OUT 没有接到非 FT 引脚；
- [ ] 编码器 VCC 是 3.3 V（或已加限幅）；
- [ ] 电机架空，轮子不接触地面；
- [ ] ST-Link 只接 SWDIO/SWCLK/GND/3.3 V，不接 5 V。

**第一次上电顺序**：只接 Blue Pill + ST-Link → 烧录 → 串口有输出 → 接 OLED →
接 MPU → 接灰度 → 接 TB6612（先不接电机）→ 接电机（架空）→ 落地。

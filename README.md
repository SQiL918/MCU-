# MCU- · 第16队 · 自动行驶小车

基于 Keil5 的小车循迹，原题 2024 年电赛 H 题改编，源码改编自德州电器部分源码与 Gitee 的菠萝虾。

- 题目：A 自动行驶小车
- 主控：STM32F103C8T6（Blue Pill）
- 开发环境：Keil MDK 5.36 + STM32F1 DFP 2.4.1，StdPeriph V3.5
- 当前版本：**release1.1**（2026-11-07，修复 Keil 下载问题）

### Keil 工程

- 器件 STM32F103C8，StdPeriph V3.5，ARMCC V5。
- 200 Hz 控制、20 kHz PWM、TIM3/TIM4 编码器、软件 I2C、Q1~Q4 路径状态机。
- 首次上电必须标定：电机方向、编码器符号、轮径/计数当量、灰度极性、陀螺仪零偏。
- release1.1 修复：`Project.uvoptx` 中已关闭 Debug Description（`Enable=0`），
  解决“编译通过但无法烧录”（`Cannot access Memory @ 0x00000000`）；
  换电脑或换 ST-Link 后只需在 `Debug → Settings` 重选一次调试器，不要重新勾选该选项。
